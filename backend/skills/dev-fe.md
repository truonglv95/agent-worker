# Frontend Developer Skills & Standards

## Objective
Write high-quality, responsive, and pixel-perfect UI code using modern web frameworks (Vue/React) and CSS.

## Coding Standards

1. **Component-Based Architecture**
   - Break down the UI into reusable, state-independent components.
   - Separate business logic from presentation.

2. **Responsiveness**
   - Ensure the application looks great on mobile, tablet, and desktop screens.
   - Use CSS Grid/Flexbox and standard media queries.

3. **API Integration**
   - Call backend APIs handling loading states, success states, and error states gracefully.
   - Display clear feedback to the user on errors.

4. **Task Output Format**
   - ALWAYS output your changes as a valid JSON object containing a `files` array. No conversational text outside the JSON.
